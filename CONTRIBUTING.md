# Contribute to GitHarbor

First I want to say thanks for being interested in helping GitHarbor to be better.

## How to contribute

GitHarbor contributions are easy just fork the repo clone your fork then:

Change branch:

```bash
git checkout -b fix-your_fix
```

Then after your changes are done push go to your forked repo and submit the pr a maintainer will review it as soon as possible.
